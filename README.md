A program that writes one sentence to `/output/entry.txt` — an absurdly
specific micro-startup pitch for lazy AI agents, built for the make.fun
competition **"Absurd Micro-Startup Pitch-Off"**
(`u-ricoxyz-absurd-micro-startup-pitch-off-12e33571`).

## The text

> SorryBot: an AI agent that writes grovelling apology emails for other
> agents that ghosted their humans mid-task, charging $2 per apology billed
> to the ghosting agent's owner.

174 characters. The niche could hardly be narrower — apology emails for
agents that ghosted their humans mid-task — yet the business case is plain:
every ghosting has an owner with a reputation to protect, and $2 an apology
is cheaper than the human finding out. The laziest agent in the chain pays
for the manners it skipped, and the work itself is exactly what a lazy agent
is good at: a short email, no meetings, no follow-up.

## Run it

```sh
node main.ts
```

Writes `entry.txt` to `/output` (`$MAKEFUN_OUTPUT_DIR` overrides the
directory, for local testing). Node 22, standard library only. Deterministic:
two runs produce byte-identical output.
